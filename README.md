## 🔐 [Password Security App](https://github.com/ChampCTE/password-security-app)

🌐 https://password-security-app-one.vercel.app

A privacy-focused full-stack web application built with **Next.js** and **TypeScript** that evaluates password security and generates secure passwords in real time.

Unlike many online password checkers, every calculation is performed locally, meaning passwords are never stored or sent to a server.

### Features

- Password strength analysis
- Real-time password feedback
- Entropy calculation
- Crack-time estimation
- Secure password generator
- Automatic language detection
- Automatic light/dark mode detection
- Fully responsive design

### Planned Features

- Check whether a password has appeared in known data breaches
- Advanced password security recommendations
- More detailed security metrics

**Built With**

Next.js • React • TypeScript • Firebase • Vercel
