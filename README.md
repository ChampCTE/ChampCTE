# Featured Projects
 
## 🐦 MagpieHub
 
A cloud-based **bookmark manager** that keeps all your bookmarks in one place, synced across devices and browsers. No more bookmarks scattered between work and personal accounts.
 
🌐 https://magpiehub.app
 
**Status:** beta completed, alpha coming next.
 
### Features
 
- Cloud sync across devices and browsers
- Categories with drag & drop ordering
- Import bookmarks from any browser (HTTPS links and HTML files only)
- Sign in with email or Google, with email verification and password recovery
- Interface in English and Spanish
- Waiting list for the alpha, with consent and unsubscribe at any time
### Under the Hood
 
- React + TypeScript frontend, deployed on Vercel
- Node.js backend API on Google Cloud that verifies the user's identity on every request
- Firebase Authentication for sign-in
- Firebase SQL Connect with Cloud SQL (PostgreSQL) for a relational data model
- Per-user data isolation enforced on the server, not only in the interface
- Restricted bookmark import to reduce the risk of malicious uploads
### Roadmap
 
- **Alpha:** Free plan plus a Pro plan with subcategories, text search, and avatar upload
- **Later:** mobile-friendly PWA experience and a possible browser extension
**Built With**
 
React • TypeScript • Node.js • Firebase Authentication • Firebase SQL Connect • Cloud SQL (PostgreSQL) • Google Cloud • Vercel

## 🔐 [Password Security App](https://github.com/ChampCTE/password-security-app)
 
🌐 https://password-security-app-one.vercel.app
 
A privacy-focused full-stack web application built with **Next.js** and **TypeScript** that evaluates password security and generates secure passwords in real time.
 
Unlike many online password checkers, every calculation is performed locally, meaning passwords are never stored or sent to a server.
 
### Features
 
- Password strength analysis
- Real-time password feedback
- Entropy calculation
- Crack-time estimation
- Secure password generator
- Automatic language detection
- Automatic light/dark mode detection
- Fully responsive design
### Planned Features
 
- Check whether a password has appeared in known data breaches
- Advanced password security recommendations
- More detailed security metrics
**Built With**
 
Next.js • React • TypeScript • Firebase • Vercel
